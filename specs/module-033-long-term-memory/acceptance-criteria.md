## 1. 功能验收

### 1.1 记忆提取器

- [ ] 📋 对话→提取事实 — 验证方式：extract_facts(query, answer) 返回结构化 facts 列表（LLM 提取）
- [ ] 📋 importance 过滤 — 验证方式：importance < 0.6 或空 content 被丢弃
- [ ] 📋 提取失败降级 — 验证方式：LLM 异常/超时返回 []，不抛错
- [ ] 📋 输出 JSON 结构 — 验证方式：{"facts": [{"content", "importance"}]}

### 1.2 语义去重

- [ ] 📋 相似 >0.95 视为重复 — 验证方式：同义偏好二次写入 → 更新而非新增（库内条数不涨）
- [ ] 📋 不同事实正常新增 — 验证方式：不同偏好各自新增
- [ ] 📋 去重失败降级 — 验证方式：去重检索异常 → 正常新增（不阻塞）

### 1.3 动态 K 召回

- [ ] 📋 均值>0.85 → K=5 — 验证方式：高质量候选召回 5 条
- [ ] 📋 0.75-0.85 → K=3 — 验证方式：中等质量召回 3 条
- [ ] 📋 <0.75 → K=1 — 验证方式：低质量宁缺毋滥只召回 1 条
- [ ] 📋 空候选 — 验证方式：无候选返回空，不崩

### 1.4 格式化注入

- [ ] 📋 记忆带 "[长期记忆 - 日期]：内容" — 验证方式：_recall_memory 输出格式化字符串
- [ ] 📋 无日期时省略 — 验证方式：无 created_at 记忆不带日期

### 1.5 自动写入接入

- [ ] 📋 chat 结束异步提取 — 验证方式：knowledge 路径对话后触发 _persist_memory（不阻塞响应）
- [ ] 📋 闲聊不提取 — 验证方式：intent=casual_chat 不触发
- [ ] 📋 实时不提取 — 验证方式：intent=realtime 不触发
- [ ] 📋 fire-and-forget — 验证方式：create_task 后台执行，响应立即返回
