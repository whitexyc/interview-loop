## 1. 功能验收

### 1.1 核心功能验收

- [x] 📋 round 0 向量超时降级 — 验证方式：模拟向量检索超时，链路不崩，返回图结果
- [x] 📋 HyDE 缓存 — 验证方式：两次检索，第二次命中缓存（日志显示）
- [x] 📋 整链路预算 — 验证方式：设置小预算，到点强制进入生成
- [x] 📋 提前终止 — 验证方式：round 0 充分即返回
- [x] 📋 检索质量不下降 — 验证方式：hybrid Hit@5 ≥ 0.91（基线）

### 1.2 边界条件验收

- [x] 🔲 round 0 图超时：降级为仅向量结果
- [x] 🔲 HyDE 缓存不可用：不缓存，正常生成
- [x] 🔲 总预算已到且无 docs：返回空
- [x] 🔲 提前终止阈值：不足 3 篇不跳过第二轮

### 1.3 异常场景验收

- [x] ⚡ round 0 两路都失败：返回空（不崩）
- [x] ⚡ HyDE LLM 失败：用原始 query
- [x] ⚡ 缓存失效：正常重新检索
