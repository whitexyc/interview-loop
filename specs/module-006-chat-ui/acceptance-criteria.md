# 验收标准 — Module-006: 前端知识库问答界面

- [ ] 聊天页面可输入问题并发送
- [ ] AI 回答以气泡形式展示
- [ ] 引用标记 [1][2] 正确渲染为可点击样式

- [ ] 消息历史保留在对话中
