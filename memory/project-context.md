## 2. 技术栈
> 详见 `tech-stack.md`，此处仅保留摘要。
- 后端 (Java): Spring Boot 3.2 + MyBatis-Plus + PostgreSQL
- 前端: React 18 + TypeScript + Vite + Ant Design
- AI 层 (Python): FastAPI + LangChain + pgvector
- 中间件: Redis
- 向量库: pgvector (PostgreSQL 扩展)
- AI 供应商: OpenAI / Claude API
- 部署: Docker Compose
