# 项目经历 — Agentic RAG 技术文档知识库问答系统

> Agentic RAG · 2026.07 - 至今 · 大模型应用开发工程师（全栈）

---

面向技术笔记分散、无法直接交互问答的痛点，将 **124 篇技术笔记（累计约 156 万字、平均每篇 1.3 万字）** 转化为可交互、引用可溯源的 Agentic RAG 技术文档知识库，支持任意用户以自然语言问答。主导整体架构设计、检索质量与系统稳定性的持续优化，建立可量化、可回归的评估体系驱动每一轮迭代。

## 核心工作

1. **Agent 能力链路**：Self-RAG 流水线（意图路由 → 混合检索 → 语义重排 → 自我反思纠错 → 自适应重查 → 逐句幻觉检测 → 流式生成）+ ReAct 工具化 **10 个可注册工具**（混合/全文/向量/图谱检索、记忆召回、证据链验证、自适应重检、工作笔记）；回答附引用溯源 + 逐句可信度色标（supported/inferred/unsupported）。意图路由用**本地小分类器**（bge-m3 嵌入 + 逻辑回归，337 条人造标注训练，Accuracy 1.0）做主力——毫秒级、输出校准真概率；**确定性信号复核**兜底（检索侧事实，不用 LLM 校验 LLM，失败自动回退 LLM 零影响）。幻觉检测用 **HHEM 专职裁判**替代"写答案的 AI 自己批自己"——LLM 拆句 + 专职检测模型逐句判分（110M 参数全本地，证据取自最高分文档），解决同源验证。

2. **三通道混合检索与版本化评估**：全文（jieba 预分词）+ 语义向量 + 知识图谱三路融合——**RRF 倒排融合**（`Σ1/(60+rank)`，只看排名对量纲鲁棒；消融实测图谱入融合后 Hit@5 **0.99**，图谱单通道贡献 **+0.24**）；分诊式查询改写——FTS 术语静态分诊（精确 query 直接检索零成本）+ 改写保真预检（余弦阈值回退）+ 原/改写并行检索绝对余弦择优（改错可回退）；父子两级分块——子块检索、父块作答；自建 golden 评测集 **112 题**，Hit@k/MRR 版本化回归，实测 Top-5 命中率 **0.99**（RRF 三通道 0.9905）。

3. **多层记忆与进化机制**：长期/短期/会话三层记忆 + Agent 跨轮次工作笔记 scratchpad；记忆进化——提及强化、指数衰减、短期自动升级长期、会话递归摘要；多用户上下文独立互不串扰，记忆与知识库双向隔离。

4. **反馈闭环**：AI 回复下 👍👎 反馈落库（feedback 表），作为意图/充分性两个分类器的再训练数据源，形成"使用 → 反馈 → 再训练"自改进飞轮。

5. **可靠性工程与评估体系**：时限预算强制封顶 + 每步级联超时 + Agent 工具 15s 超时围栏 + 输入校验 + 多供应商降级链 + 参数化缓存（命中 3ms）+ 嵌入/重排全本地离线推理，最坏情况延迟有界、服务不中断；**Prompt 变体评测**（同一任务 N 版提示词跑 golden 对比 Accuracy/kappa/耗时，只度量不替换）驱动提示词优化。

6. **MCP 标准工具服务**：ToolRegistry 工具经官方 MCP SDK（FastMCP）暴露为标准 MCP Server——**6 个只读检索工具**（混合/全文/向量/图谱检索 + 实体提取 + 记忆召回）双传输对外提供：**stdio**（本地 Cursor / Claude Code 即插即用）+ **Streamable HTTP**（挂载进现有 FastAPI `/ai/mcp`，Bearer token 认证 fail-closed）；工具定义单一事实源（改 ToolRegistry 描述 MCP 自动同步）；理解 MCP 边界——它是管道不是判断，工具阶段切分 / HHEM 验证 / 审计三层治理保留在管道之外。

7. **Agent 行为评测闭环**：检索质量之外为 **Agent 行为**建立评估闭环——工具调用明细落库（trace_id/参数/成败/耗时，只记实际执行）+ 36 条任务级评测集（覆盖六类路径：单轮/多轮/闲聊/实时/重检/记忆）+ 三层指标（任务完成率 pass^1/pass^3——k 次独立尝试全成功才算对、工具调用正确率——该调的调了没多调参数类型对、成本——步数/token/P50-P95），判定全确定性（不用 LLM 评 LLM）；**首跑即抓到真实盲区**：generate_answer 在 agent 循环内死锁（阶段切分只暴露检索工具、推进条件却要求先调生成工具——鸡生蛋），A/B 双配置定位修复后真实轨迹出现生成调用且任务通过——数据驱动修复闭环。
